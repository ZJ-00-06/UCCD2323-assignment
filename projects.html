Smart Campus Vision

Project Overview: Designed to modernize university campus security. The system utilizes CCTV network feeds to perform real-time object detection and spatial crowd density tracking.

Key Features:
  • Real-time human detection and tracking using custom fine-tuned YOLOv8 model.
  • Automated alerts triggered when restricted zones are accessed after hours.
  • Dashboard visualization built with Streamlit for campus security staff.

Tech Stack: Python, PyTorch, YOLOv8, OpenCV, Streamlit, Docker

Campus RAG Assistant

Project Overview: An intelligent conversational AI tailored for university students, solving hallucination issues by constraining responses to verified course documents and syllabus PDFs.

Key Features:
  • Retrieval-Augmented Generation (RAG) framework using LangChain and ChromaDB.
  • Fully local LLM inference running via Ollama (Llama 3 / Mistral) for privacy.
  • Source attribution showing exact PDF pages used to synthesize answers.

Tech Stack: LangChain, ChromaDB, Ollama, Llama 3, Python, Fast API

💻 GitHub Repository
Autonomous Navigation Bot

Project Overview: A compact 4-wheeled robotic platform built for indoor autonomous mapping and goal-driven navigation without relying on GPS signals.

Key Features:
  • 2D LiDAR mapping powered by Cartographer SLAM algorithm.
  • Dynamic path planning and real-time obstacle avoidance via Nav2 stack.
  • Custom telemetry interface integrated with ROS2 and RViz.

Tech Stack: ROS2, C++, Python, LiDAR, Raspberry Pi 4, Nav2

X-Ray Lesion Detector

Project Overview: A medical imaging AI tool designed to assist healthcare professionals by highlighting potential lung opacities and pulmonary anomalies in digital radiographies.

Key Features:
  • Semantic segmentation using U-Net architecture trained on public medical datasets.
  • Grad-CAM heatmaps showing exact visual regions triggering model decisions.
  • DICOM image format support and patient privacy compliance.

Tech Stack: TensorFlow, OpenCV, U-Net, DICOM, Python
